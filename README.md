# Chemboy Photography site

Open `index.html` in a browser to view the one-page site. It has no build step. The moon/sun control switches between dark and light themes and remembers the choice when browser storage is available. Click a gallery frame to open the photo viewer.

The logo crop in `assets/chemboy-mark.png` comes from the supplied Instagram screenshot. The wedding, portrait and studio photographs are temporary references; replace their image URLs in `index.html` with Chemboy Photography's own work before publishing. Instagram's logged-out view showed the public grid but required sign-in to reveal the original post image, so the requested hero photo still needs the original image file or a direct image URL. Booking buttons point to `@chemboy_photography` because no phone number or email address was supplied.
