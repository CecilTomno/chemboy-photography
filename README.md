# Chemboy Photography site

Open `index.html` in a browser to view the one-page site. It has no build step. The moon/sun control switches between dark and light themes and remembers the choice when browser storage is available. Click a gallery frame to open the photo viewer.

The logo crop in `assets/chemboy-mark.png` comes from the supplied Instagram screenshot. The hero film in `assets/chemboy-hero.mp4` is the supplied video; it plays muted by default and the on-video sound button enables audio at 22% volume. Wedding, portrait and studio photographs elsewhere on the page are temporary references; replace their image URLs in `index.html` with Chemboy Photography's own work before publishing. Booking buttons point to `@chemboy_photography` because no phone number or email address was supplied.
